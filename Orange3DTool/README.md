双击同目录的“橙子3D一键启用工具.exe”。必须完整解压，保留 PresetShaders 和 ThirdPartyNotices。
启动实际请求 Steam 最新工坊下载；启用/关闭 3D 会同时管理 ZombieBuddy。
实验 DLSS 下载、启用和本地组件导入已移除。
旧版已有安装仍可按原备份恢复；现代设置页仅在存在旧安装记录时显示恢复入口。

旧蓝色版本仍保存在相邻 PZ3DManager 文件夹。旧备份路径保持不变。
本目录 DLSS-Cache 是开发时实际下载测试缓存，不随发布 ZIP 打包；不要公开分发。

开发编译：运行 Build.ps1（Windows .NET Framework 64-bit compiler），生成 x64 可视化程序。
文件级测试结果见 验证记录.md。源代码保留便于审查，程序不运行远程安装脚本或修改安全规则。
