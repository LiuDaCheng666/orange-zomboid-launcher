## 由网站负责人在官方系统完成

1. 在[全国互联网安全管理服务平台](https://beian.mps.gov.cn/)核对当前办理要求，完成账号与实名认证。
2. 按官方表单填写主体身份、有效证件、实际地址、联系资料，以及网站负责人、网络安全责任人等字段；具体字段与材料以官方系统和当地审核要求为准。
3. 核对网站名称、域名、服务商、IP、接入方式和网站服务内容，准备官方要求的责任材料。
4. 若符合阿里云 ICP 订单条件，可按[数据码指导](https://help.aliyun.com/zh/icp-filing/basic-icp-service/using-data-code-for-public-security-network-filing)迁移可复用信息；仍须完成实名、主体与网站信息及申请提交，数据码不等于备案通过。
5. 负责人本人确认后提交，跟踪审核和补正。获得真实备案号与官方展示要求后，再安排页脚展示。

身份、地址、签名、证件照片、责任书和数据码均不要写入仓库、工单或公开日志。本次未收集这些资料，未代填或提交申请。不得用 ICP 号代替公安备案号，不得编造公安备案标识。
