## Native compatibility and evidence limits

`componentsAction` continues to accept `{component,operation,confirmed}` with independent `buddy`, `viewpoint`, `chinese` IDs and the legacy `base` combined operation. The three cards retain existing fields and evidence. Chinese installation from a clean setup obtains Buddy and Chinese only; Viewpoint installation obtains only missing Buddy/Viewpoint sources. Removing Viewpoint retains Buddy native files and launch arguments. Buddy removal detaches its dependent core/default rows while preserving downloaded Workshop payloads. Legacy base/all removal still uses the combined cleanup, and profile formats remain unchanged.

Old `base` receipts remain readable. Independent cards show `legacyAppliedUtc` plus a warning when only a combined receipt exists; they remain `sourceState=unrecorded` until independently recorded. A combined hash is never reused as proof of a separate component. Buddy evidence includes native DLL bytes and deployed-file drift.

Steam WebAPI `GetPublishedFileDetails` POST timed out, including a bounded 15-second curl attempt recorded by the controller. Viewpoint, Chinese and optional remote manifests are therefore **unverified**. Query failure means unknown, never “latest” or “no update.” Generic hidden/removal/incompatibility boilerplate on Steam pages alongside active item content is insufficient evidence that an item is removed. This audit does not establish gameplay compatibility, rendered texture correctness, server support or live runtime loading, and it does not supersede author requirements.
