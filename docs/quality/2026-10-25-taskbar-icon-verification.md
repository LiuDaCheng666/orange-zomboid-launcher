# 1.2.18 任务栏图标验证

日期：2026-10-25（Asia/Shanghai）。

## 问题与修正

主程序 PE 图标与正常窗口标题栏为橙子，不能据此认定任务栏正常。早期预览设置了 `ShowInTaskbar=false`，窗口图标检查没有覆盖任务栏；用户实际确认仍为蓝白默认图标后，候选未发布。

本机 Windows AppsFolder 中的 `velopack.OrangeZomboidLauncher` 仍解析到已不存在的 `%LocalAppData%/OrangeZomboidLauncher/current/橙子启动器.exe`。开始菜单残留同应用标识的旧英文快捷方式，而有效的新中文快捷方式指向 D 盘。旧失效入口已逐字节备份到本地证据目录后移出；系统关联并未立即恢复，不能把移出旧入口当作已经修复。

最终发行使用一次性迁移后的固定 AUMID `OrangeZomboidLauncher.Launcher`。官方打包元数据同时驱动进程标识与安装、更新快捷方式，之后保持该值，不随版本变化。PackageId、更新公钥、更新源顺序未改变。没有增加自动删除快捷方式、清空系统图标缓存或修改系统安全设置的代码。旧固定任务栏项可能需要用户重新固定新版；不承诺自动迁移旧固定项。

另补齐 `--icon`，使官方 Setup、Update/Squirrel 与主程序、包装安装器和免安装入口使用相同品牌。实际最终 wrapper 中的 `Setup.Official.exe` 资源必须提取检查，不能以外部构建副本替代。

## 验证结果

- 最终候选：`E:/Projects/OrangeLauncher/dist/1.2.18-taskbar-20261025-final`。此前同版本候选均未发布。
- 旧候选的两个更新组件图标检查先失败；最终八个真实程序图标像素一致，通过 Windows PowerShell 5.1 验证。脚本保留 UTF-8 BOM。
- 两个最终分发包中的 `sq.version` 均包含固定新 AUMID。旧候选先因旧关联失败，最终候选通过。XML 禁用 DTD 与外部解析。
- 原有签名、精确文件清单及未知文件拒绝测试通过；新增根 `setup.ico` 仅在新版本放行且须逐字节等于已签名应用图标，篡改拒绝测试通过。
- 实际官方原生升级测试通过：从旧默认图标/旧应用标识升级到新标识，重启进程的真实 locator 返回新 AUMID，根 Update.exe 已替换为橙子图标；个人数据和浏览器资料保留，独立游戏及计时进程继续运行并正常结束。证据：`artifacts/uniquelifecycle-c3a2095db71547719a4a4770b7693cb0`。
- 独立安装器测试通过：中文向导选择非系统盘、创建/不创建桌面入口、新 AUMID 与中文桌面/开始菜单快捷方式一致、正常官方卸载。使用隔离 1.0.0 模板，证据：`artifacts/installer-native-3186d9974be0`。一次误用生产版本模板的测试因版本不匹配拒绝，已修正测试输入，未将其当作产品安装故障。

- 实际 1.2.18 正式程序集继续通过四份真实日志和未知模组调用帧测试；生产解析器没有改动，1.2.17 的全量语料证据仍适用。软件发布器 15、发行准备 9、SSH 策略 7 项通过。
