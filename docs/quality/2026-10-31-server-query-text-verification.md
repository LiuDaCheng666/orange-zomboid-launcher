## 原因和修改范围

搜打撤测试服的公开 A2S INFO 回包在名称字段末尾包含不完整的 UTF-8。旧版使用严格解码，名称解码失败导致整包有效的人数、容量与延迟被丢弃，推荐列表显示“信息不完整”。捕获的原始公开回包 188 字节，SHA-256 为 `1b329c4d1065ac75f50e0915aec46eb93959d09d7a5e733baf16e18e022b6835`；保留为 `tests/fixtures/a2s-truncated-name.bin`。当时回包人数为 4/80。

`ServerProfiles.Packet.Str()` 仍验证字符串边界和真实终止符，仅将显示文本的 `DecoderFallbackException` 转为缺失文本，继续读取有效数值。真实截断、非法容量、标志与扩展布局仍返回无法确定状态。`Clean(null)` 保持 null。

生产 `app.js` 仅修改三处：在线响应明确返回不可用名称时不再保留旧实时名称；大厅回退到来源标题；详情同步非交互标题容器，移除已经失效的重复名称副行。推荐、个人、游戏收藏和大厅共用处理。未改变布局、查询周期、重试策略、任务锁、授权或连接方式。没有修改或重启游戏服务器。
