`a52b3d5` 将自动启动改为一次原生权威检查，拒绝时回传结构化报告供修复/排序。身份发现仍考虑全部已知候选，完整图元数据仅展开本次选中模组及依赖；提交前重新读取相关原始字节及目录成员，保持当前资源、进程、路径和最终配置核验。不使用持久化安全缓存，也不靠目录名猜模组 ID。

## Java 加载呈现

已完成本机 42.21 API 与绘制顺序研究。早期资源索引在 Loading Mods 之前，原来的阶段观察遗漏了它；`%.1f` 的内存格式造成 0.1 GiB 的视觉跳变。新实现正在通过真实阶段观察、约 250 毫秒的扫描标签节流、独立首帧动画时钟、MiB 内存显示和三种中心动效处理这些问题。

服务器交互背景必须经游戏队列排在原生控件之前；不能直接把 CPU 侧 UI 调用当作 GPU 绘制顺序，也不能在 swap 时盖住取消/授权/排队控件。研究记录详见本地 `task-2-research.md`。

根会话已查看生产绘制的启动 1280×720、存档 640×480、服务器 1920×1080、同时含左右日志 1280×720，以及真实隐藏 GL 队列绘制的首帧/成长帧。发现阶段/内存条被过度简化后，已通过回归重新保留；服务器信息仍在根据用户追加需求扩展，最终画面待再检查。实际签名探针还发现 `SpriteRenderer.drawGeneric` 返回 `TextureDraw`，已纠正初始 fixture/runtime 的 void 假设，避免真实 API 下背景被安全跳过。

2026-10-26 用户要求增加本次服务器的 IP、人数、游戏时间、游戏日和进入进度。只读字节码已确认：排队信息带 Short/Byte/Integer 型人数与日历字段，Immediate 消息不携带这些字段；`receiveGameTime` 正常返回后才能认定服务器时钟已同步。`GameTime.getDaysSurvived` 是玩家生存时间，`getServerTime` 是单调同步时钟，均不能作为服务器世界日期。

该扩展已随 `ef139c8` 实现：精确捕获当前 canonical host2/port4/name6，其余认证参数不读取；独立服务器操作资料跨重复的授权/角色/世界交接保留，取消、切服、本地存档使旧资料及异步结果失效。普通连接通过自有单 daemon、单最新等待请求及自有 UDP socket 的一次性 A2S_INFO 查询补人数；当前排队响应优先于迟到公开查询。游戏日期/HH:mm 来自本次排队数据或已同步的 GameTime，世界天数需要当前 GameTime 同步证明；不用旧值、PC 时钟或本地已复制玩家数量代替。

独立 Task2 复审发现服务器 `SendDone` 只是发送确认、原生 done 仍为 false，旧 fixture 却总设为 true，掩盖了等待确认时提前清空场景和资料的问题。`9bee161` 按实际分支改 fixture 并先复现 RED，再拆分 SendDone 的交接判断：服务器等待期间保留完整资料/场景，实际 Done、本地完成、退出及原有错误/交互才交接，原始确认异常保持原样。独立定向复审已确认修复，未发现范围内新增破坏。

最终 Java 后台整套通过：原 session 28、新模型 23、资料代际 11、A2S 解析/回环/挑战/取消/超时 92、生产视口/帧 63、原 premain 51、新生命周期/队列 31、资料 premain 16、队列隐藏 GL 17、实际类精确 API 非初始化验证 18，以及原 GL/包审计。根会话另在该定向 Java 修正之前以重建 JAR 编译原生套件，`--headless` 787 条 PASS、0 FAIL。最终 Java 证据为 `artifacts/ingame-startup/tests/task-2-senddone-green.txt`，前次完整日志为 `task-2-final-run.txt`；原生证据为 `artifacts/loading-refinement/final-new-jar-native.log`。

根会话已检查最终包含完整资料及左右问题的 640×480/1280×720 画面：中央资料最小 12 px、行距至少 18 px，与底部问题区分开；已向用户展示示例数据预览。上述画面及隐藏 GL 均不代表实际服务器交互已经验收。

公开查询默认使用当前游戏端口，不扫描其他端口；服务器不回应或独立公开查询端口不同则隐藏未取得的值。UDP 的 2,500 ms deadline 包含 DNS 前后检查，但 JVM/OS DNS 本身不可中断，可能占用该单独 worker 更久，游戏/绘制线程不会等待。入服人数是本次实际查询/排队响应的观测值，非持续轮询。未知/FBO/交互路线保留原生画面。
