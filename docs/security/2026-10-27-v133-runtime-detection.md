# 1.2.33 更新后主程序与快捷方式隔离

2026-10-27 用户报告更新后桌面快捷方式消失，安装目录入口也无法启动。本机证据已确认两者属于同一次 Defender 隔离。当前没有修复运行，也没有认定误报。

- 04:19:18，Velopack 1.2.161 记录 1.2.29 → 1.2.33 应用成功，发现并更新原有桌面和开始菜单快捷方式。发行清单仍为 `Desktop,StartMenuRoot`。
- 04:19:20.896，Defender 实时保护检测主程序，名称 `Trojan:Win32/Prowloc.A!cl`，ThreatID `2147727733`。
- 04:19:39.648，隔离成功；1116/1117 事件资源包括安装目录 `current/橙子启动器.exe`、桌面 `橙子启动器.lnk`、对应进程和卸载登记。
- 04:21～04:22，用户启动根目录执行入口后，Velopack 报 `Unable to find executable to start`，目标是已经被隔离的 `current/橙子启动器.exe`。
- 实际检查确认主程序和桌面快捷方式缺失；根目录入口仍在；开始菜单快捷方式仍在，但目标文件不存在。

检测时安全智能版本为 `1.461.214.0`，引擎 `1.1.26090.9`。后续只读查询构建目录原始主程序时，系统同样返回“文件包含病毒或潜在的垃圾软件”。没有尝试恢复、复制回安装目录、执行或绕过访问阻止。
