**Architecture:** Retain only cleanup/migration support for the deprecated bridge. Modern and classic component install/update must never redeploy it. Remove its custom mode/key UI; show author-native controls instead. Cleanup removes only the exact owned bridge mod row/files and aim-fallback settings, preserves default BOM/maps/custom blocks and all author files, and does not depend on a running client/server/Java state. Real locked-file errors remain visible; cleanup must detach the mod even when a loaded JAR cannot yet be removed. No process is stopped. Already loaded Java retires on the next player-initiated game restart.

An unused compatibility asset in the launcher core is not deployed to the game; historical source/tests are not erased. No change to Buddy/game Java authorization or server rules. Do not automatically alter other players' game configuration merely by opening/updating the launcher; their explicit gun component install/update cleans the deprecated patch. Current user's explicit removal authorizes narrowly scoped local cleanup after fixture verification.
