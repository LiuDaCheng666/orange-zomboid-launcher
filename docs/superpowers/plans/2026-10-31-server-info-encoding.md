# 服务器查询坏文本兼容修复计划

目标：真实 A2S 名称包含被截断的 UTF-8 时，继续读取合法人数、容量和延迟；名称返回空值，由现有页面回退到推荐/个人/收藏名称。

沿用现有隔离工作树 codex/velopack-updates。不变更游戏服务器配置、协议请求、缓存、并发、授权或任务锁。不更换 UI 布局或新增警告流程。

1. 新增真实188字节回包 fixture 与聚焦 native encoding 测试组；先确认当前解析失败。
2. 仅在字符串边界已确认后容忍 UTF-8 文本解码失败，仍拒绝损坏布局、超长字段、非法人数和不完整扩展字段。地图/目录/版本等同类字符串一并检查。
3. 运行 encoding、共享查询、保存列表、推荐列表相关原生回归。实际 UDP 经共享查询器验证推荐、个人及收藏/大厅请求路径。
4. 后台实际点击生产页面，核对绿灯、计数、名称回退、详情、返回与刷新；独立 Agent 审查源码和最终截图。
5. 构建候选并用候选原生读取器真实查询目标服，清理本次大体积测试副本，记录实际覆盖边界。正式发布单独记录，不把本地通过说成用户当前安装已生效。

证据：上次原包SHA256 1b329c4d1065ac75f50e0915aec46eb93959d09d7a5e733baf16e18e022b6835；未改名时生产1.2.47失败，内存中仅换名字即读出4/80。此次修复不使用改过名字的包替代原包验收。
