# 游戏默认优先使用独显

用户已要求设置本机，并让启动器默认处理，免去玩家手动设置。

目的：防止独立 Java 启动绕过原游戏 EXE 的显卡偏好。沿用现有启动入口，不新增页面、确认框、后台任务或启动拦截。

方案：在实际提交进程前，为实际 EXE 写入当前用户 Windows 图形偏好 `GpuPreference=2;`。Steam 入口在提交前设置所选游戏目录的原生 EXE 和 Java EXE。保留同一值内的其他图形选项；已为高性能时不重复写。此偏好也适用于 AMD 等混合显卡，最终设备仍由 Windows/驱动选择。不修改全局显卡模式、Steam 参数、游戏文件或模组授权；写入失败仅记录日志并继续启动。

未采用：改 NVIDIA 全局配置或切换 MUX（影响其他应用、厂商限制）；只设置启动器 EXE（不能覆盖游戏 Java 子进程）；修改第三方 Java/游戏 EXE（二进制无须改动）。
