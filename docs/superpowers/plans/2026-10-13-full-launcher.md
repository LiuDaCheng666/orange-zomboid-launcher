# Full launcher implementation plan

Goal: complete the user-approved desktop launcher workflows, preserve canonical source, safely publish original source and remove obsolete test artifacts.
Architecture: existing C# host owns native writes/launch safety; independent data services for profiles/sorting, Steam work processes, screenshots/favorites, task history and playtime. Embedded Web UI uses allowlisted actions, explicit writes and truthful task results.
Stack: Windows x64 .NET Framework4, WebView2, native Steam interfaces, Windows built-in SQLite, HTML/CSS/JS. Four independent domains use dispatching-parallel-agents; root owns integration and task/playtime services. No shared controller/Web edits between workers.

Global constraints: tests use synthetic E:/Projects/OrangeLauncher/artifacts fixtures, no personal default/save/approval/DB writes or real server logins. No new Javaagent/author JAR rewriting. Steam password and tickets never stored/logged. No server changes. No licensed assets in public Git. Main source retained permanently; prior build directories deleted only after source/known artifact validation.
