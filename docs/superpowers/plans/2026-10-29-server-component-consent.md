# 服务器连接组件选择与原生 Java 授权

用户已明确本轮设计：连接服务器时由玩家选择跟随服务器或强制保留本地组件；服务器后来要求的新 Java 模组交给 Buddy 游戏内原生授权。直接执行该已批准设计，不增加新的产品策略或审批步骤。

## 功能合同

- 入口复用所有服务器连接按钮最终调用的 `launchExperience('server', id)`，选择发生在 `startupBegin` 之前。
- 弹窗两个直接动作：“跟随服务器”（推荐）、“强制加载本地组件”；可取消或关闭。说明强制加载的 3D/Java 组件可能不被部分服务器支持，出现红字、功能异常或连接失败。
- 本次选择用 `serverComponents: 'follow-server' | 'force-local'` 传递，只属于本次启动，不改永久清单，不重写 Steam 参数，不卸载 Buddy。
- 跟随服务器：服务器的模组与顺序为准，不把本地已选组件追加进去；保留可用的 Buddy 客户端加载器支持服务器 Java 模组。
- 强制加载：保留本地所有已启用组件，不以固定五项 3D 白名单缩小范围；服务器已有的相同 ID 不重复加载。无关单机普通模组不因这项选择混入联机。
- 联机不使用 `policy=all` 自动授权，也不能使用 `deny-new` 或启动时固定 JAR 清单提前拒绝服务器新模组。新文件应能到达 Buddy 原生授权路径，同意后才能加载，拒绝不得执行。
- 启动器配置、命名配置、Steam/原版与快照路径均需核对；不得用统一前端选项掩盖后台某一路径不生效。快照文件和授权记录不可被联机临时行为改写。
- 单人、正常主菜单与快照隔离规则保持原合同；仅联机会话调整，退出后临时状态清理。

## 工作与验收

- [ ] C#/Java 先写失败用例，验证两模式的实际会话清单、同 ID 去重与来源选择；再改生产实现。
- [ ] UI 先写失败用例；覆盖首页、个人列表、推荐列表共用入口，取消/Escape/关闭/切页/配置 A→B→A，不创建错误启动或残留遮罩。
- [ ] 用真实 Buddy 版本运行授权调用路径：服务器新 JAR 能触发原生询问，允许/拒绝结果真实约束执行；不得用合成 `allows=true` 替代。
- [ ] 核对 Buddy 未启用/不存在、服务器首次新增 Java 模组、不同来源相同 ID、单机原有严格规则与快照原件独立。
- [ ] 独立子 Agent 严审弹窗截图、操作效率、文案和 API/原生授权行为，修复后复验。
- [ ] 最终候选完整打包，使用包内页面连接真实隔离控制器验收；分别记录源码、模拟传输、JVM、原生 UI 和实际游戏的覆盖边界。

分工：native agent 负责 C#/Java、原生策略和针对性测试；UI agent 负责生产页面与 DOM 测试；独立审查 agent 负责 Buddy 授权流程和截图。主任务负责合同、集成、构建、复看与证据，不操作用户前台，不主动发布未经本轮验收的更新。

- 2026-10-29 新反馈中的两次 Buddy 安装均读取到 202 个文件、14,466,055 字节，在复制第 48 个文件后失败。隔离目录复现截图同构的 `ConsoleModApprovalFrontend.java` 目标超过 260 字符时普通文件接口报 DirectoryNotFound；Windows LongPathsEnabled=0。复用项目原生长路径适配，保留完整文件，不通过跳过源码或改系统设置掩盖失败。
- 已覆盖真实 202 文件来源的完整复制、逐文件哈希、原来源不变及真实卸载；合成深层来源、更新、取消与失败回滚另行验证。DOM 点击必须覆盖目标深路径与已复制深文件后的取消清理。
- 用户新增服务器列表设计：紧凑卡片显示简短介绍、人数、延迟、红绿黄状态；详情显示完整介绍和多图，无图不保留巨大封面占位。

- Java 文件授权提示只属于对应操作与页面，不残留到服务器页；原生授权本身保留。
- 用户后续明确详情布局：顶部单个图片展示窗口，用左右箭头手动切图，下方为完整富文本介绍。采用可选 `descriptionHtml` 字段，旧 `extendedDescription` 继续作为纯文本回退；后台可视编辑与源码模式需真实保存、重读、导出，并与启动器显示格式一致。
- 加载页面内存条必须融入整页最顶部、横贯全宽，无独立卡片／窗口／外框；大数字与阶段标题排在同一背景，阶段标签位于下方并保留全宽。旧独立框方案已被用户明确否决，不能拿其“字号大、无重叠”通过记录背书。只做相关共享场景离屏截图与布局回归，不以此冒充实际游戏窗口验收。
