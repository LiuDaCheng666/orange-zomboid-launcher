# 3D 快捷启用、模组双栏与后台读取修复

本轮以 2026-10-29 用户最后确认的范围为准：模组区只有 3D 快捷启用、模组配置、Steam 工坊三个入口。名称翻译功能在查看来源工具后由用户取消，产品不包含该词库、开关或第三方程序。

## 产品合同

- 常用快捷五项：货架、真实天气、模型扩展、老余汉化、树木。自动准备 Buddy/Viewpoint，最终选择写入同一配置的普通模组清单，不要求第二次 Java 启用。按随后用户截图反馈，同页恢复 Buddy/Viewpoint 基础卡，提供实际启用、停用、卸载当前配置副本三种操作。
- 普通列表的详情在条目下原位展开，大封面、完整介绍、工坊原页同区展示；正文按来源 token 懒读取，不截断已成功读取的本地介绍，重新读取目录后失效旧缓存，同 ID 不同来源的展开状态独立。
- 普通模组和仅依赖 Buddy 的 Java 模组统一管理；红色标签说明 Buddy 依赖，不以这个标签断言任意作者模组无需额外安装。
- 左侧全部模组、右侧已启用，独立搜索；右侧平滑拖放、上下移动、声明依赖排序。前置已在前面为绿、在后面为黄、未启用为红；提示不阻断保存和启动。
- 工坊保留默认浏览、搜索、版本/分类/排序组合条件、分页和失败重试；条件提交到 Steam 查询接口。
- 后台读取不占修改任务锁；迟到回复不能覆盖其他配置、草稿或授权目标。状态轮询不能因为自己观测到 busy 就永远停止。
- 普通存档的“查看模组”使用同一双栏工作方式，保存仅写所选存档；绑定快照的存档直接打开对应快照配置，新增模组继续复制到快照本地，不能误改原存档后仍启动旧清单。
- Buddy/Viewpoint 的一次启用完成所需文件和配置；已启用状态只提供停用与卸载。旧引用可直接解除，不要求先二次安装；卸载不删除外部工坊来源或其他配置的内容。
- 不操作用户前台、Steam 配置、真实游戏或存档。此次按用户明确要求验收启动器部分，不启动实际游戏。
