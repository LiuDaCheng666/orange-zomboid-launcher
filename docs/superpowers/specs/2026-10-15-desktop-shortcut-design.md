# 安装器桌面快捷方式补充规格

2026-10-15，用户追加要求修复“安装后没有桌面快捷方式”。源码核查：InstallerForm完成页只提供打开程序，InstallerInstallService只部署自有文件，没有任何.lnk创建实现。不是已发现的Windows权限拦截。

建议采用默认勾选“创建桌面快捷方式（当前用户）”，允许取消；相比强制创建，它保留玩家选择；相比仅完成页手动创建，不要求每位玩家额外操作。创建不需要写入注册表，不创建所有用户或开始菜单入口。

- 仅安装记录与全部自有文件核验成功后创建。指向准确安装根目录的橙子启动器.exe，工作目录为该根目录，图标取已核验EXE；无额外启动参数，不启动游戏或Steam。
- 使用系统当前用户桌面已知目录，兼容重定向/OneDrive桌面，不硬编码C盘。快捷方式位置本身属于桌面需求，不改变程序安装路径；不在C盘安装程序内容。
- 原有同名文件不覆盖；安全选择独立有界后缀。拒绝可疑重解析点/目标变更，不替换外部文件。创建失败保留安装成功，完成页说明未创建及具体原因，日志保留。
- 在已绑定installationId的runtime内保留精确快捷方式路径及本工具创建文件哈希等所有权证据；不增加十八项签名自有文件集合。
- 卸载只有路径、文件哈希及目标仍匹配本次安装才删除该.lnk；任何不一致/玩家已修改/外部替换均保留。删除失败明确提示，不递归删除桌面，不写注册表。
- 安装器更新不重复创建快捷方式；完整免安装ZIP不静默往桌面写文件。现有旧安装不在本轮未经用户操作自动补写桌面。
- 行为测试只用fixture桌面和安装根目录，覆盖默认勾选、取消、安装失败不创建、正确目标/图标、同名冲突、重定向、错误权限、外部替换保留及自有卸载。禁止测试修改真实桌面。
