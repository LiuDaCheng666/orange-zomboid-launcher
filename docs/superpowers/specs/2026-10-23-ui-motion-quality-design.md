# OZL 全功能复验与界面动效精修

用户要求检查全部功能、继续美化启动器和官网，并让软件动画更平滑。沿用此前确认的 PCL 式空间层级、橙色品牌、原封面、紧凑组件卡片及模组列表＋详情；不再进行重复方案确认。工作目录仍为 `E:/Projects/OrangeLauncher`，在当前目录的修整分支实施，不复制工作树。

## 视觉与交互

- 统一深色／浅蓝主题的文字层级、间距、圆角、边框和轻量玻璃质感。状态色继续明确区分已启用、可更新、失败、未处理，不靠颜色单独表达。
- 首页保留大封面，主启动操作清晰；组件、存档、服务器与模组页维持紧凑信息密度，原图不拉伸。设置、内存、维护和帮助页采用同一节奏，不添加口号、重复说明或防御性文案。
- 平滑处理页面切换、导航、抽屉、弹窗和图片切换。优先动画 opacity / transform；不对尺寸、大面积模糊或滚动位置逐帧运算。轮询和进度刷新不重新播放页面入场，不丢输入焦点、草稿、列表滚动或弹窗状态。
- 快速来回切换时取消过时动画，不叠加动画队列；关闭／离开后释放短期动画。系统减少动态效果设置下关闭非必要动画；后台标签不持续运行新增装饰动画。
- 官网延续简约暖白／橙色风格，优化三个既有页面的排版、导航与交互，保持清晰功能介绍和紧凑长度；使用本轮新版启动器截图，不生成新素材或复制 PCL 资源。

## 功能复验

对首页配置与启动目标、三个核心组件及扩展、Java 授权、模组配置与依赖排序、工坊、存档、服务器与大厅、服务器工坊清单、画面／光影设置、内存、维护、任务、计时、帮助与在线更新逐项记录测试证据。真实输入、回执乱序、取消、失败重试、脏草稿和重复操作边界保留。

原生功能用隔离目录、合成配置和注入 Steam 边界执行；删除存档、清缓存、重建工坊等只操作测试夹具。不启动真实游戏、不订阅／退订实际工坊、不修改玩家或服务器、不占用户前台。安装器被隔离和实际进服等未能完成的测试单独列明，不能用夹具通过冒充真实成功。
