## UI 排列

- 六个现有一级入口移到顶部：启动、模组与组件、存档、服务器、设置、帮助。路由标识和所有功能保留；下载／工坊、光影、画面、内存、维护等继续保留现有二级入口。
- 首页左侧集中放游玩配置、启动目标、必要的当前配置摘要和唯一“启动游戏”按钮。管理配置、捕获、编辑、预览、导入／分享、重新读取等收进明确标注的展开区；不是删除功能。
- 首页右侧使用原有 `home.png` 大幅场景封面，不生成新图。桌面展示区域约占首页横向空间四分之三，随窗口高度扩展；1366×768 的预览图片区为 1016×617 CSS px，不再压成 160px 横幅。
- 根据最新要求，右下角增加轻量只读状态浮层，显示本机游戏版本、当前实际启动内存与下次启动已配置的组件（名称和数量）。游戏版本只读取当前所选游戏目录的有界 `version.txt`；缺失、格式异常或不安全路径显示未知，不猜测。内存不用尚未应用的配置草稿；组件已配置不冒充本次已加载。小窗口避免标题与状态浮层相互覆盖。
- 计时、最近存档／服务器、Java 授权入口使用底部简短状态和明确入口；完整信息与原操作仍可展开。真正的待授权、启动阻断、恢复待处理、部分失败必须突出显示，不为画面美观隐藏重要风险。
- 小窗口保留字体可读，优先收起摘要而非缩小所有字体。733×507 预览已核对启动按钮在首屏；更窄窗口允许合理重排与滚动。
- 组件保留紧凑卡片、原作者封面、版本／状态与安装卸载入口；介绍和证据仍按需展开。顶部集中安装核心、检查更新和恢复全部组件，避免每张卡片重复工具栏。
- 其他页面沿用既有模组列表＋详情、存档、服务器筛选排序与设置功能；统一导航、留白、行高、标题层级和工具栏位置，不新造功能。黑金／浅蓝主题保留；状态同时用文字和颜色。

## 新增恢复按钮

- 组件页新增“恢复全部组件”。它表示停用组件并撤销本工具能识别的启用配置／部署文件，方便手动重新安装；不是系统恢复出厂或 Steam 验证游戏。
- 点击后只弹一个明确的确认框，说明影响范围和保留内容；取消不执行任何修改，确认后才进入现有受保护的全组件卸载路径。若启用了完整屋顶，合并显示作者清理要求；未明确确认不得跳过现有屋顶移除保护。
- 覆盖组件页全部受管扩展及基础 3D／Buddy、模型、汉化、枪械／桥接；基础关闭时沿用现有实验加载器停用行为。保留工坊下载文件和订阅、普通第三方模组、光影包、个人参数、游玩配置、账号密码、授权决定及存档。不改已有存档独立模组清单或服务器配置。
- 游戏运行、待恢复会话、其他冲突修改和未知／不安全文件继续阻止操作；不自动接管未知启动项，不为此退出 Steam，不自动重新安装或下载。
- 接入已有任务进度和日志。能测量的阶段报告真实进度，不能测量的使用不定进度；每项完成／失败可核对。部分失败不能显示全部已恢复；结束后重新读取本机状态，玩家自行点击安装。
