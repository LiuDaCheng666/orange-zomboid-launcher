# Java 组件统一管理

用户已在上一轮确认“工坊选择 → 下载识别 → 补齐依赖 → 组件中心启用”的方向，并要求实现。本次沿用已有界面，不另建一套管理器，不正式发布。

## 操作

- 工坊链接下载后读取实际 mod.info 与 JAR；已有适配组件走原安装器，标准 Buddy Java 组件走通用管理。
- 启用时按依赖顺序处理本地依赖；缺失依赖复用已有工坊来源解析与下载，不依赖标题猜测后直接启用。无法定位时显示具体模组及原因，取消和失败释放占用。
- 停用/屏蔽仍保留普通 Lua 模组选择；工坊更新后重新屏蔽同一来源、同一模组身份的新 Java 声明，保留新作者元数据，启用时恢复更新后的声明。启动前执行这一步，不为无管理记录的用户扫描全部工坊。
- 独立代理、DLL 和手动覆盖游戏文件不自动推断安装方案；列出具体安装方式，保留已有专用适配。
- 显示实际阶段、数量和下载字节；组件卡片以名称、状态、启用/停用/卸载为主，加载细节折叠，保留工坊链接。

## 验收

使用隔离文件测试启用依赖顺序、更新后停用保持、再次启用读取新声明、重复操作、取消、失败和特殊安装类型。使用实际 Web 页面点击至原生控制器与文件结果；实际查看截图。真实工坊内容只读复制到隔离环境验证识别；实际游戏验证单独记录，不能用合成 JAR 冒充。保护用户游戏、资料及前台，不修改网站或部署文件。
