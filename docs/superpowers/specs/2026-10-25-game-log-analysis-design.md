# 通用游戏日志分析与启动问题展示

用户在 2026-10-25 批准真实语料调研方案，并要求实现、用真实日志测试后发布；新增明确要求为任意模组通用解析、独立一级导航、中文含义及原文证据、启动画面右下角问题区和易读界面。

实现采用本地、只读、有界的结构化解析。输入支持当前用户游戏日志和通过原生选择器导入的 TXT / LOG / ZIP / 目录。异常及 B41/B42 调用帧提供模组、脚本、函数和行号；未知 ERROR/WARN 也保留，不以模组名称或样本名单决定支持范围。源文件、归档成员和导出位置不接受网页提供的任意路径。

按游戏会话及每次连接尝试分析时间顺序；进入游戏、连接被接受、加载耗时和模组自己的 timeout 是不同证据。结果区分最后尝试失败、运行中问题、断连和不确定；多会话缺乏可比较时间时不制造统一的“最后一次”。同一会话的 console 与 DebugLog 只在日志尾部规范化匹配时合并。

独立“日志分析”页提供本机、文件/ZIP及目录入口、后台进度、取消和脱敏报告导出。结果优先显示；卡片包含中文解释、建议、涉及模组、次数与原文证据，来源 ID 可对应脱敏文件名。浅色、深色和最小窗口均验证。修复与帮助页链接该功能。

启动监控复用同一解析器。右下角显示观察到的问题并打开只读详情；原顶部进度与内存、中央标识动画、左下角日志和严格就绪信号保留。滚动日志驱逐前提取问题，避免一次输出突发将错误漏掉；观察不控制游戏进程，不因一般红字改变启动成败。

验收包含真实本机与下载语料、明确世界加载阻断/必需资源退出/运行期脚本错误/重试成功案例，以及任意模组改名、未知错误、隐私、编码、ZIP、安全路径、读取限制和取消。原始玩家日志不入库。容量受限必须标记不完整，不能声明所有模组的根因均已解决。

软件发布只写不可变发行文件、更新清单、发行元数据与本次说明。服务器使用工程固定密钥及主机指纹；网页、图片、脚本、网站 current、Web/SSH 配置均不变。
