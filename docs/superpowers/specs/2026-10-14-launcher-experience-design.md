# 橙子启动器配置式启动和故障诊断设计

按用户确认的 PCL 借鉴方案完善现有启动器：清楚呈现下一次游玩的目标和配置，跟踪真实操作阶段，并根据日志提供可核对的故障证据。保留 Windows x64、C#/.NET Framework、WinForms 和 WebView2，不重写平台，不复制 PCL 代码、图标或界面素材。

## 范围和安全边界

- 使用当前 `feature/core-self-update` 分支；不创建新工作树，不合并 main，不推送或发布。
- 组件保留紧凑卡片；模组保留列表和右侧详情；保留黑金与浅蓝主题、原作者封面。
- 不自动下载、升级模组、退出 Steam、启动游戏或批准 Java 文件。玩家明确操作才修改本地文件。
- 测试使用合成游戏、用户和数据目录；不修改真实 Steam、游戏配置、存档、分页文件或注册表。
- 内存上限仍按总物理内存计算。实时可用内存仅作提示，不拦截合法配置。
- 配置完成、文件存在、授权允许、启动进程、读档或进服请求提交、实际游戏加载均是不同状态。
- 分享只包含模组 ID、顺序和已核实设置；不包含账号密码、绝对路径、授权决定、第三方文件或任意命令。
- 组件兼容信息基于已有本地和安装证据；没有作者合并公告时不编造退役提示，不自动停用扩展。

## 启动前体检和阶段

只读体检返回稳定的项目 ID、状态、中文说明、修复入口和总体是否可启动。核对游戏目录、JSON 启动参数、Buddy 文件、旧参数、待恢复会话、工坊重建、默认模组依赖及 Java 授权。内存和未经游戏内验证的组件属于提醒，不一律阻止启动。拒绝未知路径、重解析点、异常大小及畸形配置。

点击启动时按普通、存档或服务器目标重新体检，不把旧结果当通行证。联机目标会排除普通本地模组，所以普通模组的缺依赖不应误拦联机；无法安全解析或恢复的配置仍应阻止。阶段消息区分核对配置、准备启动目标、释放 Steam 查询、启动进程和等待游戏反馈。提交请求成功不能显示进服成功；无法观测的游戏加载进度使用不定进度，不编造百分比。

## 完整游玩配置

独立保存命名配置，包含目标类型（普通、存档、服务器）、本地目标标识、普通模组顺序、可选启动内存、光影 ID 和已存在且可编辑的 Viewpoint 参数。服务器账号和密码继续由已有服务器配置管理；游玩配置仅关联服务器 ID。

创建和更新配置可捕获当前实际设置。选择配置只改变启动器选择，不立即写游戏。应用前展示变化并确认；采用完整预验证、文件快照和可恢复事务，游戏运行、待恢复操作、外部修改或失效设置时拒绝覆盖。明确列出受影响文件。不改地图、角色和车辆文件。

普通目标使用普通模组清单；存档目标修改仅该存档可编辑的模组清单；联机目标不套用单人普通模组清单，保留现有受管理客户端组件。退出后的临时联机清单恢复继续使用现有会话机制。内存与画面设置是全局游戏配置，不声称每个配置拥有完全隔离的游戏或工坊版本。

导出带版本的 JSON 清单，可复制分享；导入只创建新配置并显示待核实依赖，不自动订阅、启用或覆盖已有配置。导入删除机器专属目标关联，使用普通目标；未知版本、过长内容、未知字段、无效 ID、只读参数和任意路径拒绝。

## 故障诊断和证据导出

只读取已知游戏日志、虚拟机崩溃日志和工具日志的有界内容。结果显示时间、文件来源、匹配原文、结论强度和下一步。区分日志明确报出的错误、推测关联和证据不足；不用单个模组名字判定元凶。

初始规则覆盖 instrument 或启动 Java 插件失败、无法分配堆、Java OutOfMemoryError、系统提交内存不足、缺失类或依赖、重复模组、原生崩溃和订阅未确认。无匹配时明确无已识别证据。旧日志标记历史，不当作当前会话故障。

诊断报告只导出脱敏文本，不上传；删除 SteamID、连接账号密码、令牌、完整用户路径和 IP 等敏感信息。读取失败本身显示为诊断警告，不伪装成无错误。

## 统一 UI

一级导航按首页、模组与组件、存档、服务器、设置、帮助归类；原有路由仍可访问，二级导航保留工坊、画面、光影、内存、维护入口。首页以游玩配置和一个主要启动按钮为中心，提供最近目标、当前配置摘要和待处理事项。

模组支持全部、已启用、未启用、有更新、缺少依赖筛选；多选后才显示批量添加或移除清单的工具栏，保留排序预览和未保存草稿。下载不自动启用，取消订阅和本地停用不能混为一谈。

网络查询、任务和局部刷新保留焦点、输入、滚动与选择。仅真实冲突的修改按钮不可用；已允许授权不可重复允许。状态同时有文字与颜色。正文目标 14px、辅助信息 12px 以上，避免靠缩小文字提高密度；小窗口允许合理重排。

## 验收

1. 新增原生测试分别验证只读体检、配置持久化和应用事务、导入安全及日志诊断脱敏；先观察缺少功能的失败，再实现。
2. 浏览器测试验证首页选择不写配置、体检阻止失效启动、实际阶段文字、模组筛选批量操作、草稿保护、诊断和分享流程。
3. 合成故障测试验证外部修改、重解析点、未知字段、部分写入和恢复、陈旧日志；不真实运行游戏。
4. 两套主题逐页截图，检查 1366x768、1920x1080 和高缩放可读性；运行已有原生、浏览器、核心更新和打包回归。
5. 新候选版本为 1.2.0；验收通过后只构建新的本地签名核心包、安装包及 ZIP，不覆盖 1.1.1 或上传线上更新源。
