# OZL 官网功能介绍与动效修订

用户要求直接修改，不再重复确认；沿用既有阿里云官网、图标、封面和源码目录。仅改网站，不构建或发布启动器、不更改下载与签名更新源。

## 内容与布局

移除首页功能区的开发版本对照、演示数据脱敏、中性占位等内部验收说明。版本、平台、大小只在下载区出现；帮助和更新记录保留真实发布信息，不把尚未发布的能力写成现有下载功能。

首屏明确介绍 ZombieBuddy、Viewpoint 3D、中文汉化，以及模组、存档、服务器和维护。功能区采用左侧五个常驻图文标签、右侧实际截图与三条具体能力；未选中的标签也有用途描述。五组分别为启动与存档、组件、模组、服务器、内存与维护。覆盖存档封面与回收站删除、依赖排序与配置、个人服务器与大厅、内存设置、清缓存、工坊重下与进度日志。不宣传自动修复所有冲突、任意服务器完整清单查询等未验证能力。源代码核对未发现完整存档备份入口，因此不宣传存档备份。

保留五组实际界面、深浅色切换、原尺寸放大、下载、QQ群、源码及备案入口，不新增装饰性图片或跟踪脚本。桌面保持三屏以内，手机功能标签改为紧凑横向选择与换行摘要，不产生横向页面溢出。

## 动效

加入一次性滚动进入、标签状态过渡、切换截图的短淡入与位移、按钮悬停、弹层打开动画；不自动翻页，不滚动劫持，不循环漂浮。动画约 180–460 ms。减弱动画偏好关闭非必要运动。脚本关闭或观察器不可用时正文仍可见。

## 验收与部署

先添加功能摘要可见、详情切换和真实切换动画的失败测试，再实现。运行全部网站测试，覆盖 1440、1280、768、390 宽度、两主题、键盘、减弱动画、禁用脚本、下载备用入口。后台截图检查完整布局。复用固定 SSH 指纹部署工具，保持正式 1.2.13 下载与原签名清单不变；上线后执行线上回归。
