# OZL 1.2.15

- 安装与自动更新改用开源 Velopack 框架，保留安装版和免安装 ZIP，不再包含原来自制的更新助手、卸载器；仍需要框架自带的官方 Update.exe。
- 软件内检查、下载、明确确认后一键更新并重启。优先从 [orangezl.com](https://orangezl.com/#download) 获取更新，只有连接或传输失败才回退到本仓库 GitHub；签名或哈希校验失败直接报错。
- 保留原有发布签名身份，更新完整应用包并验证版本、长度及 SHA-256。
- 更新保留个人配置和运行数据，后台计时监控继续运行。安装目录内存在其他运行程序时阻止更新，避免结束游戏或服务器进程。
- 修复 Steam 配置中的制表符或换行触发错误解析的问题，内存设置不再依赖 Steam 登录、配置解析和启动参数检查。

## 首次迁移

**1.2.14 及更早版本需要手动迁移一次：下载完整安装版或 ZIP，安装／完整解压到新的独立目录，不要覆盖旧安装。** 现有个人设置继续使用，无需重装游戏或组件。完成迁移后，安装版和免安装版均使用新版的软件内更新。

安装版使用 Windows“设置 → 应用”卸载。免安装版运行根目录的 `OrangeZomboidLauncher.exe`，请保留整个目录结构与 `Update.exe`。
