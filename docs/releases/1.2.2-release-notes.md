# 橙子3D一键启用工具 1.2.2

面向《僵尸毁灭工程》Build42 的非官方免费辅助启动器，主要管理 Viewpoint、中文适配与按需选择的扩展。

## 1.2.1 用户直接在线升级

保留现有正式1.2.1，打开顶部“启动器更新”→“检查更新”→下载1.2.2。保存未完成编辑、退出游戏后确认重启。无需先卸载、手动安装新版或退出Steam。

只更新启动器自有文件，逐项验证签名与哈希，重启后核对界面健康；不更改游戏、服务器、模组启用、光影、存档或Java授权。若存在未恢复会话或冲突，请先按提示处理，不要删除安装记录来绕过保护。

## 本次变化

- 重新排列UI：顶部六个主入口，左侧集中启动与配置选择，右侧大幅封面。原有功能保留，次要操作和完整证据按需展开；两套主题、小窗口和键盘焦点均有回归覆盖。
- 保留原来的默认封面。右下角展示所选目录的游戏版本、实际读取的启动内存与下次启动已配置组件；未知明确标记，“已配置”不等于“本次游戏已加载”。
- 待恢复配置、启动阻断、错误与已发现的Java待授权项优先展示处理入口，不被大封面挤走。
- 组件页新增“恢复全部组件”：一次确认后停用工具管理内容，保留下载、订阅、普通模组、光影、个人设置、授权和存档，之后由玩家自行点击安装。它不是Steam验证游戏，也不是清空全部模组。
- 恢复前先验证启动JSON；后续步骤失败仍保留已完成／失败的逐项结果，避免误报“未修改”或“全部成功”。运行中、待恢复、屋顶清理与未知参数保护仍保留。
- 原作者组件封面、模组列表详情、存档与服务器、内存总量政策、游玩配置和更新信任保持原有行为。没有宣称修复第三方模组贴图或游戏性能问题。

## 首次下载

- 安装版：`orange-launcher-setup-v1.2.2.exe`，按向导选择新的独立目录，自带限定自有文件的卸载器，不写注册表。
- 免安装版：`orange-launcher-v1.2.2-win-x64.zip`，完整解压后运行“橙子启动器.exe”，不要只复制EXE或覆盖已有安装目录。
- Windows x64、.NET Framework4.8；启动器界面需要微软WebView2 Runtime，安装向导本身不依赖WebView2，也不静默安装系统组件。

资源中的`.bin`、`update-manifest.json`和`.sig`供程序自动更新使用，玩家手动下载只需EXE或ZIP。网络需要能访问GitHub及其官方资源域名；1.2.1已有API403／429时的官方最新下载地址回退。

源码与包验证采用合成目录和桥接；普通恢复的原生进程拒绝分支为静态证据，UI运行锁有动态测试。在线下载验证不等于已在玩家真实安装中重启，也不证明实际进服或模组画面效果。请使用较短、独立、可写的程序目录，保留异常日志供排查。
