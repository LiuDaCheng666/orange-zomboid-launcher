# OZL 1.2.11

本版合并此前 1.2.10 的本地修复，并修正联机时的本地模组与服务器加载顺序处理。

- 保留玩家已启用、已正确安装的 3D / Viewpoint 组件；连接服务器时临时排除普通本地模组和地图，保留已启用的统一汉化。不退订、不删除工坊文件、不改服务器模组清单。
- 连接前使用 ZombieBuddy 原有接口关闭其自动提前排序，避免本地规则把 Buddy 强行放到服务器列表前面。最终仍按服务器清单和游戏依赖机制加载；这个普通排序偏好会由 Buddy 保存，没有新增 Java 桥或关闭文件校验。
- 两套统一汉化各自提取纯翻译文本供本次联机使用，保留 common / 适用版本及词条合并关系，不将汉化附带的脚本或地图带进服务器。退出后恢复本地清单，临时模组不会写进存档或复用配置。
- 首页及设置页恢复“修改内存、清除缓存、重下工坊模组、更换模组”的直接入口；打开入口不自动执行清理或下载。
- 修复指定服务器／存档启动停留主菜单的一次性请求目录、文件后缀和事件问题；请求有效期延长到十分钟，连接失败状态可追踪。“已提交连接”不等于已载入世界。

更新启动器后，下次通过新版连接服务器即可使用本次修复，不需要将全部组件卸载重装。模组实际版本、服务器要求及游戏内 Java 授权仍以游戏检查为准。

提供安装版、完整免安装 ZIP 和现有签名在线更新；保留原封面、图标和更新信任身份。实际签名文件及公开下载验证见同版本发布记录。
