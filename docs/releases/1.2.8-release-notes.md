# OZL 1.2.8 更新说明

修复两处仍然打断操作的流程：

- **删除存档不再查游戏、服务器或Java是否运行。** 玩家确认准确目标后直接尝试移入Windows回收站；失败显示实际文件错误，不会改为永久删除，也不会删除远程服务器存档。
- **普通启动提醒不再二次弹窗确认。** 启动检查通过就直接启动；Java授权状态未知、封面或介绍读取提醒不再要求每次点“继续”。这不代表自动授权Java文件，游戏原有授权流程不变。

通过的体检表默认折叠，留在封面下方，需要时自行展开。只有真正不能启动的错误才展开具体原因；自动排序入口保留。再次启动不会把上一张展开的体检表重新铺满首页。

无需重装模组。安装版与免安装ZIP使用同一签名核心；已有正式版可在程序内检查更新，下载后确认重启启动器，不需要停止本机服务器。
