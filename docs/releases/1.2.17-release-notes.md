# 橙子启动器 1.2.17

日期：2026-10-25。

- 新增独立“日志分析”，支持本机最近日志及玩家发送的 TXT、LOG、ZIP、日志目录；分析在本机进行。
- 通用识别 Lua / Java 异常、模组调用堆栈和脚本位置；重复红字合并展示，提供中文解释、处理建议、来源行号和脱敏报告。
- 按连接尝试区分连接失败、重试后进入、世界加载阻断及进入游戏后的功能异常。证据不足、日志缺失或容量受限时明确提示。
- 增加整屏 OZL 启动画面，显示真实加载阶段与内存，中央标识动画、左下角日志及右下角问题详情；授权窗口出现时让出前台。

模组名称由日志提取，不使用少量模组的适配名单。堆栈出现某个模组表示它参与了调用，不等于已确定唯一根因。分析不会自动删除游戏、存档或模组；复杂脚本问题可能需要服主或作者结合复现步骤继续排查。

安装版继续保留中文目录选择向导和中文快捷方式；同时提供完整免安装 ZIP。1.2.15 / 1.2.16 可在启动器内检查、下载并确认更新。1.2.14 及更早版本需要先完成一次新版安装或完整解压迁移。
