## 玩家使用说明

首次下载安装版，或完整解压免安装 ZIP 到新的独立可写目录；不要只复制 EXE。可信新版内使用“启动器更新 → 检查 → 下载 → 保存编辑并退出游戏 → 确认重启”。不改游戏、Steam、模组或 Java 授权，只更新启动器自有文件。

无内置信任的旧单 EXE、仍被 API 限流的旧程序，以及此前已经编号 1.2.1 的同号本地测试包，都可能需要先手动安装这次正式完整包；同号重构不是更高版本。后续更高版本才会正常提示在线升级。
