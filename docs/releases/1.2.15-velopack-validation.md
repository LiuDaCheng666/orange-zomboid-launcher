```powershell
python deploy/prepare_release.py --distribution velopack --source artifacts/velopack-final-455ad951cc174ad396ca92bc730fd7cf/release --preserved-legacy artifacts/velopack-preserved-legacy-1.2.14 --output <fresh-mirror-directory>
```

Use the Python runtime containing the existing deployment dependencies. The deployment command reauthenticates the candidate and preserved legacy bytes before opening SSH, checks the pinned server host key, verifies uploads and switches the site atomically. It publishes the new website download metadata from the signed inventory; the tracked `website/release.json` stays unchanged during preparation.
