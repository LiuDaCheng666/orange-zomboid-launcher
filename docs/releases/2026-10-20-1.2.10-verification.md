# OZL 1.2.10 local candidate verification

Date: 2026-10-20. This record concerns launcher tool discovery and direct launch only; it does not change gun bridges or production server configuration.

## Scope and root causes

- Existing memory, cache, workshop rebuild and mod-profile functions remained implemented but were difficult to discover. Added compact routes in the home workspace bar and Settings. Opening a route does not perform the underlying mutation.
- Native `getFileReader`/`getFileWriter` use the game's `Lua` cache directory, not the cache root.
- The installed game's writer permits only `ini`, `cfg`, `txt`, `log`, `json`. Original `.request` and `.status` names failed; new names end in `.txt`.
- Main-menu entry can occur before `MainScreen.delay` ends, and in-world `OnTick` is not a later main-menu retry. Added one-shot render-event dispatch.
- Extended both request expiration checks from 120 to 600 seconds. Existing private request permissions, immediate consumption, scoped cleanup and preservation of intervening player edits remain in place. Recovery covers both historical request locations.
- Added original connection-failure event paths. Did not claim persistent world-entry telemetry: the game's normal connection and save loading can reset Lua before such callbacks.
