# OZL 1.2.5 更新说明

修正同目录专用服务器被误认为游戏客户端的问题。首页状态与普通启动按 Java 的实际入口识别客户端；游玩计时不再接受专用服务器或用途未知的 Java。

无法读取或确认用途的 Java 仍保守阻止重复启动。同目录服务端、未知 Java 与客户端的文件占用保护保留；修改配置、工坊维护、指定存档／服务器直达和恢复操作仍需先结束相关占用。

提供安装版、完整免安装 ZIP 与签名更新资源。保留 OZL / Orange zombiod launcher、原封面、旧内部 EXE 路径、18 项自有更新文件及既有签名身份，历史正式资源不覆盖。更新只处理启动器自有文件，不关闭 Steam、游戏或服务器，不修改玩家存档和游戏配置。

进程与安全检查采用隔离辅助进程验证，真实游戏内加载和服务器连接未作为本次修复验证结果。发布状态及下载校验以正式发行记录为准。
