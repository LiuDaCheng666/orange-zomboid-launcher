# OZL 1.2.12

2026-10-20。修复联机准备时漏掉 TrueWeathers 视觉初始化，以及 Buddy 的自动排序选项在重载后把运行时偏好重新开启的问题。

- 从启动器连接服务器时，继续保留已启用、文件存在的 `ViewpointTrueWeathers` 客户端 Java 初始化；不加载 `ViewpointTrueWeathersGameplay`。OZL 准备清单时不重置光影目录或选择；原模组仍会更新自己的光影目录，并按其“使用 True Weathers 光影包”选项决定是否选用该包。不把该模组 Lua 强插进服务器最终清单。
- 同步关闭 Buddy 当前排序开关和保存的 `autoFixModOrder` 模组选项，使用服务器原顺序；不强求服务器把 Buddy 放第一。此普通偏好会保存，玩家自行开启后，下次 OZL 联机再次关闭。单人启动不主动改它。
- 通过末尾追加 Buddy 关闭选项并读回确认，不重写其他模组设置；已经有效关闭时不重复追加。缺少旧版 API 或无法保存时记录诊断，仍继续尝试原版连接，不增加阻断。
- 不修改游戏或第三方 JAR、不新增 Java 桥、不改变授权、订阅、服务器配置或文件校验。普通本地模组仍不带入服务器。

玩家更新启动器并重新通过 OZL 发起一次服务器启动即可使用这两处修复，不必将组件全部卸载重装。已经运行的游戏不会被启动器更新热修改；新启动流程在下次启动时应用。模组本身有新 Java 文件时仍按原版授权机制处理。

第三方光影的实际兼容和完整天气功能仍取决于原模组；服务器共享积雪、脚印和 Gameplay 不属于纯客户端光影保留。服务器锁定光影、反作弊或权限仍由游戏/服务器执行。
