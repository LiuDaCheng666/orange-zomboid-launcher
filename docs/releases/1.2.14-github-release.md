# OZL 1.2.14 发布验证

## 本次范围

官网 `https://orangezl.com` 优先检查签名更新、下载版本固定的自有资源；网络故障自动使用 GitHub 原正式渠道。保留原始清单字节、RSA/SHA-256 信任身份、18 文件清单及既有事务。

本轮继续增加新版双主题界面、三个独立核心组件、有界展示缓存和启动静默更新提示。对应源码、隔离测试和新版截图已完成；网站与最终交付验证仍在进行。[本轮记录](1.2.14-product-refresh-validation.md)与以下早期传输通道候选分开保留。不修改正式玩家或服务器配置，不自动授权 Java 文件。

1.2.13 及更早版仍使用其内置 GitHub 渠道，升级到 1.2.14 后使用官网优先的新流程。

## 域名与部署

2026-10-23 在已登录阿里云控制台新增 `@` / `www` A 记录至 `101.201.143.163`，TTL 600 秒；原 `pz` 记录未改。公共 DNS 已返回两个新记录。Caddy 正常申请公开证书，HTTPS 主站返回 200，HTTPS www 和旧 HTTP IP 返回 301 到主站；未跳过证书校验。

部署工具正常默认使用域名配置；仅显式 `--ip-acceptance` 可用旧 IP 验收模式。激活前验证、失败回退旧配置及站点，历史不可变版本目录保留。

- 新增官网源测试已观察到旧实现失败，再实施；原生服务专项最终 196 项断言通过，含官网完整下载不访问 GitHub、中途断线重试、完整性失败和取消。
- Linux 激活专项新增 HTTPS 激活与失败回退用例，7 项通过。
- 完整原生回归与 Web 25/25 组通过。后台真实 WebView／助手测试覆盖稀疏和完整版本更新、健康重开、失败回退与中断恢复，全部通过；隔离目录 `artifacts/TestFixtures/native-update-318f03de`。
- 早期官网传输通道候选 `dist/1.2.14-verified` 已签名打包，但实际扫描检测到 `Trojan:Win32/Wacatac.H!ml`，准确样本见[安全复核记录](../security/2026-10-23-1.2.14-candidate-review.md)。没有公开 1.2.14、没有修改官网最新版本、没有执行该交付候选。本轮功能改造后的最终文件尚未冻结或扫描，不能沿用早期结果。
- 先前中间构建的扫描为未发现威胁，不能用于证明最终候选安全。没有在检测后重构建规避检测，没有关闭防护或添加排除项。
- 公开发布、最终候选安装／卸载自检、旧版线上升级至 1.2.14 尚未完成；不能据专项测试声称已经交付。官网继续提供原正式 1.2.13。

体验改造代码在最终独立审查后完成1744项原生断言和41组界面回归。新目录`dist/1.2.14-product-refresh-final`仅构建一次；按需扫描未发现威胁，但实时防护随后以`Trojan:Win32/Prowloc.A!cl`隔离准确安装器，未完成安装自检，未发布1.2.14。此结果与早期传输候选分开记录，见[最终候选准确记录](../security/2026-10-23-product-refresh-candidate.md)。
