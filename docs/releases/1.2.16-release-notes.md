# 1.2.16 — 2026-10-25

- 内存设置修复跨磁盘备份引起的保存失败，保留原始配置备份。
- 保存失败后立即恢复编辑与重试，保留未保存内容。
- 恢复安装目录选择，优先推荐非系统固定盘，快捷方式使用中文“橙子启动器”。
- “内存”移到左侧一级菜单，“维护与恢复”改为“修复”。
- 多人地图区块清理兼容旧版和新版目录；没有区块时明确报告未删除。可勾选“彻底清除”，确认后删除本机多人目录的全部内容，包括角色缓存、车辆和地图标记。服务器端存档、单人存档和模组保留，本地标记等内容可能无法恢复。

已经使用 1.2.15 的用户可在软件内检查并更新。1.2.14 及更早版本首次迁移仍需下载完整安装版或免安装 ZIP，使用新的独立目录。更新优先使用 orangezl.com，GitHub 是传输失败时的备用渠道。
