# 橙子启动器 1.2.19

日期：2026-10-25。

- 本机分析主要读取 console.txt，避免同次 DebugLog 重复计数，并显示文件时间。
- 首先展示核心故障、相关模组和脚本位置；资源与待核实记录合并折叠，保留原文、次数和导出。
- 改进连接失败、断线、重试与进入后异常的区分；通用解析支持不同模组，不依赖模组名称名单。
- 启动画面优先保留关键问题，辅助记录可在详情查看。
- 修复帮助页状态读取可能跳过启动检查更新的问题，连接状态文字改为“本机服务已连接”。

支持安装版和免安装 ZIP。更新优先使用 orangezl.com，GitHub 为备用源。安装版继续提供中文路径选择和中文快捷方式。

如果旧版显示“尚未检查”，请在帮助页点击一次“检查启动器更新”，下载并确认更新，无需卸载重装。升级后的启动自动检查不会自动下载或安装。
