# OZL 1.2.7 更新说明

修复“本机只开了服务器，却无法保存配置或修改组件”的问题。配置和组件编辑不再检查客户端、服务端或 Java 是否正在运行；实际文件无法写入时才报告对应错误。多数模组和设置仍在下次游戏启动或重载时读取，文件保存成功不代表当前游戏已热更新。

启动预检现在显示具体原因。例如“老余汉化需要在 True Weathers 之后加载”，不再只给出笼统的依赖／顺序错误。仅顺序问题可直接点击“自动排序并继续启动”，不必绕着新建命名配置；排序保留现有模组，不自动订阅、安装或移除其他项目。

保存命名模组配置失败会在编辑器按钮附近显示错误，并保留草稿以便重试；启用配置时自动计算包含核心组件的最终依赖顺序。直达会话结束时，保留期间新修改的默认清单并结束旧会话，不再把它覆盖回旧清单。

同时修复组件保存与后台会话清理的并发覆盖问题；保存或捕获配置时，不再混入本工具临时添加的一次性启动模组。

安装版与免安装 ZIP 使用相同核心文件。已有正式版可从程序内检查更新，下载后确认重启启动器；不需要停止服务器。本次更新不自动修改你的游戏模组清单，不自动授权 Java，也不要求退出 Steam。原封面与软件图标不变。

发布状态、交付哈希和验证结果以正式发行记录为准。
