# OZL 1.2.12 修复与后台验证

日期：2026-10-20。范围仅为联机保留 TrueWeathers 视觉初始化和同步 Buddy 排序选项。未修改枪械、命中、服务器、Java 授权策略或 Lua 校验。

## 可复现根因与修复

- 原有联机可选扩展保留规则要求 `javaPreload=true` 和 JAR `ZB-Preload: true`。本机 TrueWeathers 3.11.3 视觉模块是普通客户端 Java 初始化，不声明 premain preload，因此被临时默认清单剔除。新增明确的视觉模块保留分支；不启用 Gameplay、未选内容、缺失文件或未就绪基础组件。
- 上次原生隔离测试漏复制正式用户已有的 `viewpoint-shaderpacks`，不能将该环境的全部缺包现象归因于正式程序。此次测试复制现有光影资源和选择，记录的是补齐后的实际行为。
- Buddy 原版 `ZombieBuddy_Options.lua` 在菜单事件将 `autoFixModOrder` 的保存值回传运行时 API。1.2.11 的一次 API 关闭不能防止它重新开启。现在同步其内存选项、保存文件中的对应行和原生运行时开关。
- 原版 ModOptions 全局 save 对未加载模组的未知行未补换行，存在拼接风险。审查还指出截断后重写在部分写入失败时可能损坏其他设置，因此最终实现使用原版 append API，只在末尾追加有效关闭行并读回确认。原版 loader 采用最后合法值；已关闭时不重复追加，所有原文件字节保持前缀不变，不调用全局 save。保存失败记录诊断并继续尝试原连接，不增加启动门槛。

## 实际原生后台连接

使用正式 1.2.12 签名核心的原有 Stage/Recover API，实际游戏 B42.21.0，目标 `127.0.0.1:16261`。独立缓存、Buddy 配置/授权副本、用户目录和临时目录；进程放在单独非可见桌面，没有切换桌面、输入、截图或前台操作。不增加测试 Java agent。

- `[Viewpoint] loaded`；TrueWeathers 3.11.3 Java 初始化 `ready`，16 个物件模型包加载；老余汉化显示钩子 ready（retransformed 204）。
- Viewpoint 实际光影列表包含 `normal, library, default, vivid, trueweathers`；选择仍为 `graphics.pack=trueweathers`，没有此前的 `graphics.pack is none of its options` 提示。Minecraft 扫描器同时把此原生目录列为 left out，不代表原生光影未加载：原生列表已明确识别。
- 原生进入服务器重载后加载 85 项，其中 83 项与服务器 Mods 清单逐项、逐序完全相同；额外仅两项纯文本汉化。`DoLuaChecksum` start/end 均出现，没有本次客户端/服务端缺文件报错。
- 重载后的 Buddy `auto_fix_mod_order=false`，保存文件最后有效的对应行亦为 false；最终 append 构建中，原 ModOptions 全部字节仍作为文件前缀完整保留。这是相对 1.2.11 重载后 true 的直接修复证据。
- Viewpoint 生成服务器场景远景；地图资源、FBO chunk 和物理网格加载完成。初次构建 `game loading took 35 seconds`，审查修订后的最终构建再次实测为 21 seconds；不是性能对比结论。
- 未发送鼠标或键盘，线程仍为 `GameLoadingState.render`。不宣称完成可操作角色进入、逐项视觉检查、枪械命中或所有服务器组合实测。
