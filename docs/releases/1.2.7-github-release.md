- 允许会话期间编辑后，退出清理保留玩家更改；组件完整读／写／回滚与清理共享原有互斥锁。后台清理遇到超过5秒的保存会重试；旧监控不清理新会话。持久配置过滤且仅过滤有有效当前会话所有权的一次性桥接 ID，普通同名／相似名模组不被过滤。
