# 1.2.44：加载性能优化与首次启动修复

- 优化加载页面长日志和较长服务器地址的文字绘制，减少重复计算，降低加载画面自身的额外消耗。
- 错误摘要改为后台读取，读取较慢时加载画面仍可继续绘制；切换连接后不再采用上一连接迟到的错误摘要。
- 修复首次启动时，加载画面盖住游戏条款确认页，导致玩家看不到下一步、无法继续的问题；现在显示游戏原生条款与操作按钮。
- 保留原有橙子图标、动画、布局、三类配色和内存展示，保持原生下载确认、Java 授权及取消操作。

同场景基准中，服务器加载画面每帧绘制耗时中位数由约 2.02 毫秒降至 0.40 毫秒；长文字的测量次数由 502 次降至 11 次。这些数据衡量加载画面自身的开销，整体进服时间仍取决于游戏、模组、磁盘和服务器。本次不将此前未复现的整机短暂卡顿列为已修复。

更新后重新启动游戏即可使用新的加载组件，无需删除存档、模组或重新配置组件。正式下载见[官网](https://orangezl.com/#download)。

Windows 发布者签名仍为 NotSigned；沿用既有免费发布方案，并保留 RSA 更新认证与文件完整性校验。
