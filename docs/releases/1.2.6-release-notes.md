# OZL 1.2.6 更新说明

1.2.5 的 Java 入口解析遗漏了标准 `-Xlog`／`-Xlog:` 日志参数，使使用这些参数的专用服务器仍被保守识别为用途未知，阻止普通启动。本版补上这些单个参数的识别，继续按实际主类精确区分客户端与服务器。

已核实的同目录专用服务器可与普通客户端启动共存。客户端、用途未知或无法核实的 Java 仍阻止重复启动；配置修改、指定存档／服务器直达、工坊维护与恢复等文件占用保护保持不变。未知参数和类似 `-Xlogger` 的选项不会被放行。

提供安装版、完整免安装 ZIP 与签名更新资源。保留 OZL / Orange zombiod launcher、原封面、旧内部 EXE 路径、18 项自有更新文件及既有签名身份，历史正式资源不覆盖。更新只处理启动器自有文件，不关闭 Steam、游戏或服务器，不修改玩家存档和游戏配置。

回归验证使用带两项日志参数的隔离 Java 辅助进程，覆盖真实 WMI 入口读取、普通启动与安全阻断；真实游戏内加载和服务器连接未作为本次验证结果。发布状态及下载校验以正式发行记录为准。
