# OZL 1.2.9

本版移除启动器自制的开镜兼容层，保留枪械作者原版。

- 不再部署 OrangeShootPresentation，也不再保存其本地瞄准模式、快捷键和旧 JAR 指纹记录。
- 枪械组件改为作者原版使用说明；保留 ShootToThrillMultiplayer、Viewpoint、汉化与作者个人校准。
- 已有玩家主动重新应用枪械组件时清理旧补丁；旧配置和直达会话不会重新带回它。打开／更新启动器本身不会暗改游戏配置。
- 清理不要求关闭游戏或服务器；实际锁定的文件报告具体路径，不强制结束进程。已加载 Java 在玩家下次重启游戏后退出。
- 安装版、完整免安装 ZIP 与程序内签名更新沿用现有渠道和身份，原封面与图标不变。

原版操作：进入第一人称，持枪右键瞄准，再按 Ctrl+V 切换腰射／开镜；改过键位则以游戏实际绑定为准。多人完整功能仍遵循作者的服务器与客户端匹配要求，不承诺纯客户端替代。
