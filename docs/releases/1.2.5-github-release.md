## 修复与边界

旧版仅按游戏 JRE 路径识别 Java，导致实际入口为 `zombie.network.GameServer` 的专用服务器被显示为游戏客户端。1.2.5 保留宽范围文件占用检查，另外按实际 Java 主类、镜像路径、PID、WMI 创建时间和重新打开后的启动时间确认客户端／服务端。

只有确认的专用服务器才从首页状态、普通主菜单启动和重复客户端检查中排除；用途未知、信息不可读或身份发生变化时仍保守拦截。游玩计时只接受明确客户端，不接受服务端和未知 Java。Java 原始命令行可能包含凭据，不记入日志或发布资料。

修改配置、工坊维护、接管、删除存档、临时启动配置和恢复仍使用原宽范围占用保护。因此同目录服务端运行时，指定存档／服务器直达等写文件操作仍可能被拒绝，不宣称所有操作均可并行。没有为修复而停止任何真实游戏、Steam 或服务端，也没有修复／重装 Steam 服务或改动真实游戏、存档、桌面、注册表、分页文件及运行中的安装目录。
