# 橙子3D一键启用工具 1.2.3

本次只调整启动器自身的更新与重启体验，不更新游戏或第三方模组，不改动原有界面排列。

## 更新流程

手动检查 → 下载并验证 → 下载完成后弹出一次确认 → 同意后自动更新并重新打开启动器。

选择“稍后”或取消后，文件仍保持准备好状态；不会重复下载或反复弹窗，需要时点“重启并更新”。打开启动器不会自动检查、下载或批准更新。

## 游戏运行时

不再仅因游戏正在运行而拦截启动器更新。只重新打开启动器，不结束游戏或Steam。受管计时与会话监控使用验证后的独立运行副本，不长期占住根目录待更新的EXE。

未保存编辑、本机文件修改、未完成的配置事务、待恢复启动会话或旧Buddy接管仍会阻止重启；程序显示实际原因，保留准备好的更新，由玩家处理后继续。它不是允许游戏运行时安装／卸载模组或改游戏文件。

## 旧版用户注意

**1.2.1／1.2.2升级到1.2.3这一次，仍受旧版代码影响：可能要先退出游戏，再手动点击“重启并更新”。** 不能通过发布新文件改变已运行旧程序的判断。上述新体验从运行1.2.3后更新后续版本时生效。

无需先卸载启动器或恢复全部组件。未知文件占用、签名校验失败或恢复冲突不会靠强制结束进程绕过；保留日志和恢复资料。

## 手动下载

- 安装版：`orange-launcher-setup-v1.2.3.exe`，使用新的独立目录，自带限定自有文件的卸载器，不写注册表。
- 免安装版：`orange-launcher-v1.2.3-win-x64.zip`，完整解压后运行“橙子启动器.exe”，不能只复制EXE。
- `.bin`、更新清单和签名供在线更新使用，不需手动逐一下载。

核心更新沿用原RSA/SHA-256、十八项自有文件允许清单、真实界面健康核验与失败回退。不是Windows Authenticode签名。不夹带第三方光影、模组本体、作者封面、用户资料或私钥；Java文件仍由玩家逐项授权。

## 安装与图标

安装器新增默认勾选、可取消的当前用户桌面快捷方式选项。安装核验成功后创建，同名文件不覆盖；创建失败独立提示，不影响安装完成。卸载只清理本次创建且未被修改的快捷方式，不写注册表；免安装ZIP和普通在线更新不往桌面静默补写入口。

程序、窗口、安装器及新快捷方式统一使用玩家确认的原创“橙色几何O＋绿叶”图标。保留原首页封面，仅参考PCL的简洁几何设计概念，没有复制其图案或素材。

测试使用隔离目录与受控进程，不替玩家实际执行更新，不代表实际进服或第三方模组画面效果已验证。
