# OZL 1.2.4 更新说明

程序显示名为 OZL，全名严格为 Orange zombiod launcher。

存档与服务器列表采用方形预览和横向信息排版；恢复结果保持独立、可折叠，完整阶段和失败内容可查看。存档删除先展示目标并确认，然后调用 Windows 回收站；失败时保留文件，不永久删除。Multiplayer 表示本机多人缓存，模组只读，删除不会影响远端服务器存档。

首页原封面保留为第一张，三个既有候选每 8 秒轮换；可前后切换、选择、暂停。悬停、焦点、后台及减少动态效果时暂停自动轮换。

指定存档或服务器直达为实验功能，仍需游戏中核对。草稿、配置绑定、启动预检、运行与恢复保护保留。内部 EXE 名、18 条更新自有路径及旧桌面快捷方式所有权格式兼容。

## 下载和更新

- 首次使用可下载安装版，或完整解压免安装 ZIP 后运行“橙子启动器.exe”。界面及新快捷方式显示 OZL；保留旧内部文件名是为了兼容已有安装和在线更新。
- 已有正式版本可在“启动器更新”中检查、下载并确认更新，校验完成后重开启动器；无需先卸载模组或恢复全部组件。
- 1.2.1／1.2.2 的旧版首次升级仍可能要求退出游戏并手动点击“重启并更新”；不能通过新发布文件改变旧程序的运行逻辑。
- 更新只处理启动器自有文件，不更新或启用第三方模组，不关闭 Steam，不修改玩家存档和游戏配置。

发布前的隔离测试与审查通过；真实 Windows 回收站、游戏读档／进服仍未作本次实测，不把模拟测试当作游戏内验证。[历史本地候选记录](https://github.com/LiuDaCheng666/orange-zomboid-launcher/blob/v1.2.4/docs/releases/1.2.4-local-candidate.md)保留原候选哈希及当时边界，正式发布的哈希和在线验证另行记录。
