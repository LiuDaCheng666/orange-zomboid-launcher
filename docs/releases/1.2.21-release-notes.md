# 橙子启动器 1.2.21

发布日期：2026-10-26

- OZL 加载画面接入游戏内渲染，启动游戏、载入单人存档和连接服务器使用不同场景，随游戏真实加载阶段交接；保留游戏原生授权和连接操作。
- 改进中央橙子的生长与旋转动画、阶段进度和实时内存显示；左下角跟随本次加载日志，右下角显示核心问题、相关模组、中文含义及原文。
- 联机加载展示当前连接的服务器名称、地址、人数与队列，以及同步到的游戏时间和游戏日；等待服务器确认时保留联机场景。
- 合并重复启动检查，优先检查本次启用的模组和依赖，保留启动取消及配置变化校验，减少进入游戏前的等待。
- 改善 Steam 游戏目录自动识别，支持常见安装位置、失效路径回退和直接选择游戏库上级目录；错误选择不会覆盖已有路径。
- 修复有效 Buddy 启动参数被误判、普通配置文字触发重复加载器提示的问题；配置失败时不再同时显示未经执行的 Steam 检查失败。

安装版与免安装版均可通过软件内更新。下载优先使用 [官网](https://orangezl.com/)，GitHub 为备用源。
