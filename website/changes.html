历史版本

1.2.40

2026 年 10 月 29 日

  • 修复 Buddy 安装复制到深层文件时误报“未找到路径”：安装、更新、停用复用、取消清理和卸载均支持 Windows 长路径，无需修改系统设置。
  • 连接服务器时可选择“跟随服务器”或“强制加载本地组件”。本次选择不改原配置；跟随服务器保留可用的 Buddy 加载器，强制模式保留本地已启用组件及依赖，同 ID 优先服务器来源。

  • 修复 Java 授权成功提示残留到其他页面，以及切换页面或配置后迟到连接回复仍继续打开旧窗口的问题。

2026 年 10 月 29 日

  • 模组配置改为全高双栏：左侧全部模组、右侧已启用模组，各自搜索；支持平滑拖动、上下移动和依赖自动排序。依赖 Buddy 的模组显示红色 Java 标签。

  • Steam 工坊支持游戏版本、分类、热门／最近更新／最新发布的组合筛选，保留默认浏览、搜索、分页和失败重试；快捷页补充原作者工坊封面。
  • 修复后台缩略图、状态及配置查询被误当作修改任务，导致按钮失效或连接被拒绝；编辑窗口关闭、重新读取、切换配置与迟到回复不再互相覆盖。
  • 修复普通 Java 模组选择、存档授权、同文件不同来源和旧快照状态不一致；补齐带前缀模组标识的依赖排序与快照读取，并保留未修改清单的原始字节。
