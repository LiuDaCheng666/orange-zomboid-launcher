开始使用

使用帮助

先确认游戏目录，再选择需要的组件与启动方式。

  1. 下载并打开

    从当前版本下载区选择安装版或免安装版。ZIP 请完整解压，不要只取出 EXE。运行环境为 Windows x64，需 WebView2 Runtime。

  2. 确认目录与组件

    使用已安装的正版游戏与 Steam 客户端。确认启动器识别的游戏目录；在组件管理中查看版本与状态，按需安装或更新。遇到 Java 文件授权提示，先阅读说明。

  3. 选择启动目标

    按需整理模组配置与顺序，再选择存档或服务器。维护或变更前，请保留重要存档备份。

常见问题

安装版与免安装版有什么区别？

功能相同。安装版提供目录选择、快捷方式和卸载向导；免安装版完整解压后运行。两者都需要保留配套文件。

更新启动器后，要重新安装组件吗？

启动器更新与组件更新分别操作。更新启动器后，可在组件管理中查看当前状态，再决定是否更新组件。

需要输入 Steam 密码吗？

不需要。使用电脑上已登录的 Steam 客户端。服务器角色账号与密码由服务器配置管理。

下载失败或遇到错误怎么办？

下载区提供官方 GitHub 备用链接。反馈时请注明启动器版本、操作步骤与错误信息，分享日志前删除账号、密码等私人信息。
