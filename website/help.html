使用帮助

从安装启动器到管理存档、连接服务器，按下面的步骤操作。3D 模组、内存设置和常用维护工具都可以在启动器内完成。

  1. 安装并打开启动器

    从下载区选择安装版，在向导中选择安装目录；或将免安装版 ZIP 完整解压到新的独立文件夹，再运行根目录“橙子启动器.exe”。需要 Windows x64、.NET Framework 4.8 和 WebView2 Runtime。

    1.2.14 及更早版本需要手动安装或完整解压新版一次，不覆盖旧目录；之后使用软件内更新。现有个人设置继续使用，无需重装游戏或组件。

  2. 确认游戏目录

    登录拥有《僵尸毁灭工程》的 Steam 账号，确认游戏已安装。检查启动器识别的游戏目录；未找到时，手动选择包含 ProjectZomboid64.exe 的游戏文件夹。

  3. 选模组，再选启动目标

    需要 3D 时，在组件页面安装并启用 Viewpoint 3D；汉化按需安装。单人游戏选择模组配置或存档；联机选择服务器。具体用法见下方说明。

3D、内存和常用维护

怎样一键启用或卸载 3D 模组？

打开组件页面，找到 Viewpoint 3D，点击安装并按提示完成所需框架和下载，下一次启动游戏时启用。出现 Java 文件授权提示时，阅读来源说明并允许所需文件。

不再使用 3D 时，点击该组件的卸载按钮。中文汉化可以单独安装；卸载 Viewpoint 不会连带移除 ZombieBuddy 框架。

怎样一键修改游戏内存？

点击左侧“内存”，选择分配给游戏的内存并保存。页面会显示系统总内存、当前设置和推荐值；保存后，下次启动游戏时生效。

清除缓存会清除什么？

在“帮助 → 修复”中点击“清除多人缓存”，默认只清理多人地图区块，保留角色、车辆和地图标记。勾选“彻底清除”后，会再次确认删除本机 Saves/Multiplayer 内全部内容，包括角色缓存、车辆和地图标记，不生成备份。服务器端存档、单人存档及模组保留；重新连接时同步服务器数据，本地标记等内容可能无法恢复。

怎样一键重新下载工坊模组？

在首页“常用工具”中点击“重下工坊模组”，核对范围后确认。启动器会清除本游戏的工坊模组文件，再通过 Steam 重新下载已订阅的模组，保留订阅关系。

这项操作适合需要重新获取模组文件时使用。下载进度、完成结果和错误信息可在任务中心查看；失败或取消后，可重试下载。只想提前下载某台服务器的模组时，使用下方的服务器“模组清单”入口。

存档和模组清单

怎样分别管理每个存档的模组？

在存档管理中选择目标存档，打开它的模组清单，即可添加、移除模组或调整加载顺序。保存的是该存档自己的清单，不会同时改写其他存档或默认清单。

存档页面也能查看封面和游玩记录，并选择存档启动。移除地图、物品等模组可能影响已有存档，修改前请备份重要存档；删除不用的存档时，确认后会移入系统回收站。

模组配置与存档模组清单有什么区别？

模组配置是可以命名、保存和复用的一组启用模组，适合为不同玩法准备多套组合。存档模组清单则对应某一个存档，用来管理这个存档使用哪些模组、按什么顺序加载。

整理清单时，可以搜索本地模组、查看前置依赖、检查缺失项，并预览自动排序结果或手动调整。切换玩法时，选择并应用已保存的配置即可。

连接服务器与提前下载模组

在启动器中保存服务器地址、端口和所需登录信息，选中后即可启动游戏并发起连接；也可以在公开大厅按人数或延迟查找服务器。

联机时，客户端必须按服务器下发的模组清单和加载顺序运行，临时排除普通单机模组，并保留已启用的 3D 和汉化。退出后恢复原来的默认清单。

  1. 第一次连接：获取服务器模组清单

    通过启动器连接服务器。游戏在连接过程中下发工坊模组清单时，启动器会记录完整清单，之后可在该服务器的“模组清单”中查看。

  2. 下次进服前：提前下载全部所需模组

    打开该服务器的“模组清单”，点击“订阅并下载”，按已记录的清单提前下载全部工坊模组。可查看逐项进度和完成结果；下载完成后，再选择服务器连接。

清单来自上次连接记录；服务器增删或更新模组后，仍以本次连接下发的最新清单为准，可能需要补充下载。若尚未记录到清单，也可导入服主提供的 WorkshopItems 或工坊 ID 列表后提前下载。

下载、更新与问题反馈

安装版与免安装版有什么区别？

功能相同。安装版提供快捷方式，通过 Windows“设置 → 应用”卸载；免安装版完整解压后运行，不需要安装向导。两者都要保留 Update.exe、current 等配套文件。

更新启动器后，要重新安装组件吗？

不需要因为更新启动器就全部重装。启动器和组件分别更新；打开组件页面查看各组件的版本与状态，有可用更新时再按需操作。

需要输入 Steam 密码吗？

不需要在启动器中输入 Steam 密码，使用电脑上已登录的 Steam 客户端即可。服务器要求的角色账号、角色密码或入服密码，在对应服务器的连接配置中填写。

下载失败或遇到错误怎么办？

启动器安装包下载失败时，请稍后重试，或加入 QQ 群反馈。组件或工坊下载失败时，先查看任务中心的错误信息，再重试。反馈问题请附上启动器版本、操作步骤和错误信息；分享日志前删除账号、密码等私人信息。
