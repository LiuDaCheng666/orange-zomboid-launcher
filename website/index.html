A FEW THINGS TO KNOW

出发前，你可能想问。

安装版是不是比免安装版功能更多？＋

不是，两者功能相同。安装版多了目录选择、快捷方式和卸载向导；免安装版完整解压即可运行。不要只提取一个 EXE，其余文件也需要保留。

更新启动器，需要重装组件吗？＋

不需要。启动器更新只更新程序自己的文件。Viewpoint 和其他模组的更新，在组件管理里单独操作。

需要在 OZL 输入 Steam 密码吗？＋

不需要。OZL 使用你电脑上已经登录的 Steam 客户端。服务器角色账号与密码是另一回事，可在服务器配置中管理。

在哪里查看源码和反馈问题？＋

源码和历史版本都在 GitHub 仓库。遇到问题可提交 Issue，描述版本、操作步骤与报错；分享日志前先去除账号密码等私人信息。
