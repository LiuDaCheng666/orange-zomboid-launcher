# OZL / Orange zombiod launcher

**当前公开正式版为 1.2.16，已于北京时间 2026-10-25 在官网与 GitHub 发布。** 安装版、免安装 ZIP 和签名更新资源同时交付，更新优先使用自己的官网服务器。准确交付与验证状态见[发布验证记录](docs/releases/1.2.16-validation.md)。[1.2.14 发布记录](docs/releases/1.2.14-github-release.md)及更早记录作为历史保留。

面向 Project Zomboid Build 42 的非官方免费辅助启动器。核心用途是管理 Viewpoint 与中文适配；其他扩展由玩家独立选择。

## 技术结构

- Windows x64、C#/.NET Framework、WinForms + 本地 WebView2 页面。
- `Orange3DTool/` 为启动器源码；`docs/` 为设计、实施与验证记录。
- `Build-VelopackRelease.ps1` 为 1.2.16 发行入口，`Build-Tests.ps1` 保留既有诊断入口；Velopack SDK、CLI 和 Newtonsoft.Json 使用固定版本与哈希，工具仅在项目内准备。运行需要 Windows x64、.NET Framework 4.8 和 WebView2 Runtime；重编 Java 桥接另需 JDK17+。
- 不请求 Steam 密码；使用玩家已登录的 Steam 客户端。Java 文件授权逐哈希确认，不自动信任作者。
- 指定存档/服务器直达功能为实验：不绕过游戏授权、存档转换、服务器规则或角色验证。

## 下载和在线更新

从[官网下载](https://orangezl.com/#download)安装版或完整免安装 ZIP，也可使用 [GitHub 最新版](https://github.com/LiuDaCheng666/orange-zomboid-launcher/releases/latest)。1.2.16 安装版由 Velopack 管理 Windows 应用与卸载登记；通过 Windows“设置 → 应用”卸载。ZIP 完整解压到新的独立目录后运行根目录 `橙子启动器.exe`；保留官方 `Update.exe`、`.portable` 和整个 `current`，不要只复制 EXE。

新版仍在顶部“启动器更新”中检查、下载，明确确认后一步更新并重新打开；选择稍后则保留“重启并更新”。更新下载经过 RSA 签名、长度、SHA-256 和版本验证的完整应用 nupkg，由官方框架替换应用，发行包不再包含自制更新助手或卸载器。未保存编辑、文件修改、配置事务或待恢复会话仍须先处理；更新启动器不等于更新或启用第三方模组。

**1.2.14 及更早版首次迁移需手动安装或完整解压新版到新的独立目录，不覆盖旧目录。** 原有 `%LOCALAPPDATA%/PZ3DManager` 设置继续使用，不改游戏、存档和工坊文件。旧版不能只靠服务器发布新 feed 获得 Velopack 协议；这一次迁移后，安装版和免安装版均继续支持软件内自动更新。

免安装运行数据位于根目录 `OrangeLauncherRuntime`，与 `current` 并列；安装版运行数据位于 `%LOCALAPPDATA%/PZ3DManager/Velopack`。执行中的监控副本单独使用 `%LOCALAPPDATA%/PZ3DManager/WorkerImages`，位于应用根目录之外。个人文件不要存入更新时被替换的 `current`。

## 既有功能与历史开发记录

## 构建与测试

1.2.16 发行入口编译主启动器及安装目录选择前端，并用固定版本的本地 vpk 生成安装版、免安装 ZIP 和完整更新包。需要 .NET Framework 4.8；不使用旧 Build-CoreRelease/Build-Setup 或旧安装器 CI 来生成新发行包。

```powershell
./Prepare-Velopack.ps1
$releaseRoot = Join-Path $PWD 'dist/1.2.16-velopack-candidate'
./Build-VelopackRelease.ps1 -SigningKey E:/Projects/OrangeLauncher-Signing/release-private.xml -OutputDirectory $releaseRoot
node --test tests/license-guide.test.cjs
npm test
```

输出目录必须全新。私钥只通过路径参数传入，不能打印、复制到包内或提交 Git。发布包包含安装 EXE、完整 ZIP、full.nupkg、框架索引、RSA 签名更新元数据及完整交付物清单；对应源码、版本和说明冻结后再构建最终包。说明通过 Build-Guide.ps1 附带完整 GPL 和第三方许可。SDK、工具及编译用依赖留在忽略目录，不进入 Git。

官网可以直接从经过签名认证的本地交付包准备发布，不以 GitHub 上传成功为前提。保留旧版 latest 与历史不可变附件，新 feed 使用 `/updates/velopack/`；GitHub 备用渠道上传同一份原始字节。具体命令见[发布指南](docs/core-release.md)和[部署说明](deploy/README.md)，准确实测边界见[1.2.16 验证记录](docs/releases/1.2.16-validation.md)。1.2.16 已先部署官网、再发布 GitHub；1.2.15 正式程序已从真实更新源检查并下载到 Ready。旧客户端的首次自动迁移仍未提供。
